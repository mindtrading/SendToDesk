Support

Contact

Email hello@sendtodesk.app. Change the address in assets/js/site.js before you go live. Include your Windows version and whether the phone and PC are on the same Wi‑Fi.

The phone cannot find the PC

  • Keep SendToDesk Desktop open.
  • Use the same Wi‑Fi. Avoid guest networks and VPNs.
  • Allow the app through Windows Firewall when asked (Private network).
  • Try QR or the 6‑digit code if Nearby is empty.

Windows SmartScreen

See the picture guide: Install SendToDesk on Windows. Click More info, then Run anyway.

Firewall alert

Tick Private networks and click Allow access. If you clicked Cancel, Windows Security → Firewall → Allow an app through firewall → SendToDesk → Private.

The .exe does nothing on another PC

Copy the entire Release folder (exe + dll + data), not just SendToDesk.exe. Prefer the zip from this website.
