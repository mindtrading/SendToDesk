# SendToDesk — Google Play ASO pack

Positioning: **this is a document scanner + passport / camera scanner that lands on the PC.** Wi‑Fi transfer is the last step, not the product.

**Play listing text cannot guarantee 5,000 organic installs per day.** See [Growth](#7-growth-and-india-organic).

---

## Core job (write every line around this)

**Old café / Xerox / photo-studio flow (what you replace)**

1. Capture the customer on the phone  
2. WhatsApp the photo to the PC  
3. Open a free background-remover website  
4. Resize / print passport size  

**Old office / café document flow**

1. Scan in another app  
2. WhatsApp the file  
3. Download on the PC  

**SendToDesk flow (pair once, then repeat all day)**

1. Connect the phone to the PC once (nearby devices on the same Wi‑Fi, or QR / code)  
2. **Passport:** Passport Photo → camera → capture → background removed on the phone → pick colour → Send → file arrives on the PC  
3. **Documents:** Scan Document → auto scan → PDF → compress to the size you need → Send to Desktop → PDF arrives on the PC  

No WhatsApp. No USB cable. No cloud upload for the transfer. Desktop app stays open on Windows or Mac.

## Product facts (do not oversell)

| Fact | Listing language |
|------|------------------|
| Brand | SendToDesk |
| Package | `com.docs.scan.sendtodesk` |
| Main jobs | Passport / ID camera photo + document camera scanner |
| Delivery | One tap send to already-paired PC over local Wi‑Fi |
| Pair once | Nearby devices, QR, or 6-digit code; same Wi‑Fi |
| Scan | On-device edges/crop → PDF or JPG + compression |
| Passport | Capture, background remove/replace, ICAO / ID sizes, send to PC |
| Extra | Share sheet can still send any file to the same PC |
| Ads | App has ads — never write “ad-free” |

Do **not** claim: government-approved photos for every country, AirDrop, Google Nearby Share as your product, competitor app names, or “works without Wi‑Fi.”

Background removal is on-device and may still need a tap of colour / crop / touch-up. Say **remove background on the phone**, not “perfect every time with zero edits.”

## 7. Growth and India organic

5k **organic**/day is not a listing promise. For *this* product, organic comes from **scanner and passport-photo searches in India**, plus shop owners telling the next counter — not from beating ShareMe on `share me`.

**Do this so the listing can rank**

- Hindi + English-IN listings and screenshots  
- YouTube: “passport size photo shop app PC print”, “scan to pdf send to computer”  
- In-app review **after a successful send to PC**, not on first open  
- Desktop installer signed, real download URL (not the placeholder in the app)  
- Pairing that works on typical café Wi‑Fi (nearby + QR fallback)  

Track in AppTweak / Console: `passport size photo`, `document scanner`, `scan to pdf`, `scan and send documents`, then transfer terms as secondary.
