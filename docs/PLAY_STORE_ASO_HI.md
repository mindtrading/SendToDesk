# SendToDesk — Hindi (hi-IN) Play Store Listing

Custom store listing for **India → Hindi**. Keyword plan follows `ASO_KEYWORD_STRATEGY.md` (Tier 1: passport size photo maker, compress pdf / KB, doc scanner, send to PC).

## Why the Hindi listing mixes scripts

Hindi-language Android users in India type most Play searches in **Latin script** (`passport size photo maker`, `pdf 100 kb`, `doc scanner`) and a minority in Devanagari (`पासपोर्ट साइज फोटो`). Google indexes the hi-IN listing for both. So:

- English keyword tokens stay in Latin script: `Passport Size Photo Maker`, `PDF`, `KB`, `PC`, `Scanner`, `Compress`
- Devanagari carries the same terms once more: पासपोर्ट साइज फोटो, स्कैनर, कंप्रेस
- Sentences are written the way a café / studio owner talks, not formal Hindi

Play counts **characters** (each Devanagari letter and matra is one). Counts below were verified; re-check in Console because it may render length slightly differently.

## 6. Console setup

- Play Console → Grow → Store presence → **Custom store listings** → create listing → target **India**, language **Hindi (hi-IN)**.
- Keep the default (en-US) and en-IN listings in English from `ASO_KEYWORD_STRATEGY.md`.
- After 30 days, compare *Store performance → Search terms* for the hi-IN listing: if Devanagari queries are under ~10% of impressions, switch the title to the Latin alternative in §1 and keep the Hindi body.
