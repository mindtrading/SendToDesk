# SendToDesk — বাংলা (bn-BD) Play Store Listing

বাংলাদেশ + পশ্চিমবঙ্গের বাংলা-ভাষী ইউজারের জন্য। কীওয়ার্ড প্ল্যান `ASO_KEYWORD_STRATEGY.md` অনুযায়ী (Tier 1: passport size photo maker, compress pdf / KB, doc scanner, send to PC)।

## কীভাবে Console-এ বসাবেন (এটা গুরুত্বপূর্ণ)

Play Console-এ বাংলার **একটাই লোকেল: Bengali – bn-BD**। আলাদা "Bengali (India)" নেই। তাই:

- **Grow → Store presence → Main store listing → Manage translations → Add languages → Bengali (bn-BD)** → এই ফাইলের টেক্সট বসান।
- এটা একটা **Translation**, custom listing নয়। যে ফোনের ভাষা বাংলা — বাংলাদেশে বা কলকাতায় — সে এটা দেখবে। দুই দেশের জন্য দুটো লিস্টিং বানানোর দরকার নেই।
- ভারতে বাংলা-ফোন ইউজার এটা দেখবে, হিন্দি-ফোন ইউজার hi-IN custom listing দেখবে, ইংরেজি-ফোন ইউজার Default/en-IN দেখবে। কোনো সংঘর্ষ নেই।
- **Bangladesh** দেশটা Phase 1-এ যুক্ত আছে (`PLAY_STORE_PUBLISH_GUIDE_BN.md` §৪)। না থাকলে Release → Production → Countries / regions-এ যোগ করুন।

## স্ক্রিপ্ট মেশানো কেন

বাংলা-ফোনের ইউজারও Play-তে বেশিরভাগ সার্চ **ইংরেজি হরফে** করে: `passport size photo maker`, `pdf compress 100 kb`, `doc scanner`। কিছু ইউজার বাংলায় লেখে: `পাসপোর্ট সাইজ ছবি`। Google bn-BD লিস্টিং দুই স্ক্রিপ্টেই ইনডেক্স করে। তাই ইংরেজি কীওয়ার্ড টোকেন ইংরেজিতেই রাখা হয়েছে, পাশে বাংলা রূপ দেওয়া হয়েছে। বাক্যগুলো দোকান/স্টুডিওর মালিক যেভাবে বলে সেভাবে লেখা।

সংখ্যাগুলো যাচাই করা (Play প্রতিটা বাংলা অক্ষর ও কার-চিহ্ন ১ ক্যারেক্টার গোনে)। Console-এ বসানোর পর একবার দেখে নিন।
