Place the Windows release zip here:

  SendToDesk-1.0.0-windows.zip

How to pack it:

1. Zip the entire folder
     desktop_app\build\windows\x64\runner\Release\
   (not only SendToDesk.exe)

2. Add these files into that zip (same level as SendToDesk.exe):
     READ-ME-FIRST.txt
     install-guide.html
     install-guide-images\

Desktop is Windows only. Android is on Google Play.
